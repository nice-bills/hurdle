The factory's only other difference is the embedded vault metadata hash. The three vaults are byte-identical to each other. - **ABIs.** `app/shared/abi`, `app/web/public/abi` and `app/web/src/shared/abis.ts` match the forge ABIs of both 7f1792a and 45bde1f exactly: every function, event (incl. `SettlerPaid`, `BondReclaimed`) and error. `deployment-1301.json` is identical in all three copies. Every `functionName` used in web/worker exists with the right arguments.
- **Error coverage.** Every custom error in the five ABIs has text in `ERROR_TEXT`. The keeper's expected reverts (`AlreadyParked`, `EpochNotOver`, `PriceDeviation`) exist. The WrappedError selector `0x90bfb865` is correct.
- **Indexer.** It decodes events with the full vault ABI, so it covers all 8 vault events plus `VaultCreated`. Health at 15:22 UTC: lag 3 blocks, 5 vaults, keeper and curator bot enabled.
- **Addresses.** README, `demo/ui/live.json`, `app/shared` and `script/out/deploy-1301.json` agree on every v4 address. `factoryStartBlock` 68509070 is the factory's creation block. Legacy start 68437200 is a safe lower bound (factory code appears by 68437300). The v3 legacy block is labelled "Earlier deployment (v3)" everywhere.
